## TL;DR

- `elm/json` の `Json.Encode` / `Json.Decode` と同じ実装パターンで、OBJ ファイルをエンコード・デコードする [[elm|Elm]] のライブラリ [elm-obj-file](https://github.com/w0rm/elm-obj-file) を作った。
- デコーダは `elm/json` と同じく合成でき、座標系を変換する関数も用意されている。

## 内容

### デコーダーパターン

[[elm|Elm]] の `elm/json` にある `Json.Encode` / `Json.Decode`（[JSON デコーダの解説](https://guide.elm-lang.jp/effects/json.html#jsonデコーダー)）と同じ実装パターンで、Blender などで使われる OBJ ファイルをエンコード・デコードするライブラリ [elm-obj-file](https://github.com/w0rm/elm-obj-file) を開発した。デコーダは `elm/json` と同じく、`Obj.Decode.map` や `map2` などで合成できる。

### 座標系の変換

OBJ ファイルをそのまま読み込むと座標系が異なり、モデルが横倒しになることがあった。そのため、[texturedFacesIn](https://package.elm-lang.org/packages/w0rm/elm-obj-file/latest/Obj-Decode#texturedFacesIn) のような、座標系を変換する関数も提供した。

### その他の API

プリミティブなデコーダとして [polylines](https://package.elm-lang.org/packages/w0rm/elm-obj-file/latest/Obj-Decode#polylines) や [objectNames](https://package.elm-lang.org/packages/w0rm/elm-obj-file/latest/Obj-Decode#objectNames) がある。高度なデコーダとして、[oneOf](https://package.elm-lang.org/packages/w0rm/elm-obj-file/latest/Obj-Decode#oneOf)、[succeed](https://package.elm-lang.org/packages/w0rm/elm-obj-file/latest/Obj-Decode#succeed)、[fail](https://package.elm-lang.org/packages/w0rm/elm-obj-file/latest/Obj-Decode#fail)、[andThen](https://package.elm-lang.org/packages/w0rm/elm-obj-file/latest/Obj-Decode#andThen)、[combine](https://package.elm-lang.org/packages/w0rm/elm-obj-file/latest/Obj-Decode#combine) がある。
