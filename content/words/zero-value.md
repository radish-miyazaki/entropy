## TL;DR

[[go|Go]] で、明示的に初期化しなかった変数や値に入る、型ごとのデフォルトの値。数値は `0`、文字列は `""`、真偽値は `false`、ポインタやスライスなどは `nil` になる。

## 仕組み

Go の言語仕様では、宣言や `new` で変数の領域を確保したとき、または複合リテラルや `make` で新しい値を作ったときに、初期値を与えなければ各要素が型のゼロ値になる。型ごとのゼロ値は次のとおりである。

- 真偽値: `false`
- 数値型: `0`
- 文字列: `""`
- ポインタ、関数、[[interface|インタフェース]]、スライス、[[channel|チャネル]]、マップ: `nil`

この初期化は再帰的に行われるので、構造体の配列なら、各要素のフィールドもゼロ値になる。

## 例

言語仕様の例では、次の 2 つの宣言は同じ意味になる。

```go
var i int
var i int = 0
```

構造体を `new` や `var` で作ると、すべてのフィールドがゼロ値になる。

```go
type T struct { i int; f float64; next *T }
t := new(T) // t.i == 0, t.f == 0.0, t.next == nil
```

## 注意点

[[初めてのGo言語 第2版 ―他言語プログラマーのためのイディオマティックGo実践ガイド 第3章 合成型|初めてのGo言語 第3章]]によると、マップのゼロ値は `nil` で、`nil` マップに書き込むと panic になる。一方、存在しないキーを読むと値の型のゼロ値が返る。

[[encoding／json／v2で何が変わる？ - v1からv2への変化を徹底比較|encoding/json/v2 の発表]]によると、encoding/json の v1 では、マップやスライスのゼロ値は JSON の `null` になる。v2 では、ゼロ値のフィールドを省略する `omitzero` が使える。
