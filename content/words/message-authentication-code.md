## TL;DR

メッセージの正真性を確かめ、メッセージを認証する技術。英語では Message Authentication Code といい、MAC と略す。

## 仕組み

任意の長さのメッセージと、送信者と受信者が共有する鍵（共有鍵）の 2 つを入力にとり、固定ビット長の値を出力する関数である。この出力を MAC 値と呼ぶ。
