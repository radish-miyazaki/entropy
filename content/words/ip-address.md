## TL;DR

IP（Internet Protocol）のネットワーク上で、通信相手のホストがどこにあるかを示すアドレスである。[RFC 791](https://www.rfc-editor.org/rfc/rfc791) で定められた IPv4 のアドレスは、4 オクテット（32 ビット）の固定長である。

## なぜ必要か

RFC 791 は、名前、アドレス、経路を区別している。名前は何を求めているかを、アドレスはそれがどこにあるかを、経路はそこへどう行くかを示す。IP が主に扱うのはアドレスである。IP のモジュールは、ヘッダに入ったアドレスを使って、データグラムを宛先に向けて送る。名前からアドレスへの対応付けは、より上位のプロトコルが受け持つ。

## 仕組み

RFC 791 では、アドレスの先頭はネットワーク番号で、その後にネットワークの中のローカルアドレスが続く。IP のモジュールは、インターネットのアドレスをローカルネットワークのアドレスに対応付けて、データグラムを届ける。

通信では、IP アドレスと[[port-number|ポート番号]]の組で送信元や送信先を表すことが多い。この組を[[socket|ソケット]]アドレスと呼ぶ。

## 例

- [[localhost|localhost]] は、自分自身を指す特殊な IP アドレス（ループバックアドレス）に対応する。
- [[dns|DNS]] は、ドメイン名を IP アドレスに変換する。
- HTTP の [[host-header|Host]] ヘッダは、1 つの IP アドレスとポート番号で複数の Web サイトを運用するときに、アクセス先を判断するのに使う。
