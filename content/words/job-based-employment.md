## TL;DR

人材を採用するときに職務内容を明確に定義して雇用契約を結び、労働時間ではなく職務や役割で評価する雇用の仕組み。欧米で広く普及しており、最近は日本でも取り入れる企業が増えている。

## 仕組み

従来の日本で一般的だった[[membership-based-employment|メンバーシップ型雇用]]が「人に仕事をつける」のに対し、ジョブ型雇用は「仕事に人をつける」。両者の違いは次のとおりである。

| 項目         | ジョブ型雇用                 | メンバーシップ型雇用         |
| ------------ | ---------------------------- | ---------------------------- |
| 基本原理     | 仕事に人をつける             | 人に仕事をつける             |
| 採用         | 欠員補充や新規ポジション中心 | 定期採用中心（新卒一括採用） |
| 等級         | 主に職務等級制度             | 主に職能資格制度             |
| 昇進・昇格   | 実績重視（年次思想なし）     | 勤続・年齢を重視             |
| 降級・降格   | 特別なことではない           | ほとんど行われない           |
| 賃金         | 職務給（職務により変化）     | 職能給（年功的に上昇）       |
| 賃金の根拠   | 市場基準                     | 内部基準                     |
| 育成         | 職務に応じた社内外教育       | 年次を考慮した社内教育       |
| 人材の流動性 | 高い                         | 低い                         |
| 雇用保障     | 弱い                         | 強い                         |
