## TL;DR

ネットワーク上で自分自身を指す、特殊な[[host|ホスト]]である。

## 仕組み

ネットワークに接続された機器が自分自身にリクエストを送るとき、ホストに `localhost` を指定すると、自分自身を指す特殊な [[ip-address|IP アドレス]]に接続できる。この IP アドレスをループバックアドレスと呼ぶ。

## 例

一般的に、IPv4 では `127.0.0.1`、IPv6 では `::1` がループバックアドレスとして使われる。

## 注意点

[[rfc|RFC]] 6761 は `localhost` を特別な扱いをするドメイン名として定めている。ユーザは、`localhost` の IPv4 と IPv6 のアドレスの問い合わせが、常にそれぞれのループバックアドレスに解決されると考えてよい。名前解決の API やライブラリは `localhost` を特別な名前として扱い、その問い合わせを [[dns|DNS]] サーバに送らないことが推奨されている。DNS サーバも、`localhost` のアドレスの問い合わせには、すぐにループバックアドレスを返すことが推奨されている。
