## TL;DR

Amazon Web Services の略で、Amazon が提供するクラウドサービス。

## なぜ必要か

AWS のホワイトペーパーによると、AWS は 2006 年に、企業向けの IT インフラを Web サービスとして提供し始めた。今でいうクラウドコンピューティングである。コンピューティング、ストレージ、データベース、分析、ネットワークなど 200 を超えるサービスを、必要なときに数秒で使え、使った分だけ支払う。前もってサーバを調達する必要がないので、初期の設備投資を、事業の規模に合わせた変動費に置き換えられる。
