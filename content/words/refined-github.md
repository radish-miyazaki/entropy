## TL;DR

[[github|GitHub]] の画面をシンプルにし、便利な機能を追加する[[web-browser|ブラウザ]]拡張。MIT ライセンスのオープンソースで、GitHub Enterprise にも対応している。

## 仕組み

Chrome などの Chromium 系ブラウザ、Firefox（Android 版を含む）、Mac、iOS、iPadOS の Safari に対応している。

## 例

README には、たとえば次のような機能が挙がっている。

- コメント欄で Tab と Shift+Tab によるインデントができる
- リポジトリのヘッダにスター数や CI の状態などを表示する
- 「+1」のようなリアクションだけのコメントを隠す
- マージした PR が最初に含まれた Git のタグを表示する

## 自分の理解

Chrome 専用だと思っていたが、他のブラウザにも対応していた。
