## TL;DR

コードの意味や動作が、ぱっと読んだだけでは理解できないコード。[[red-flag|レッドフラグ]]の 1 つである。

## なぜ必要か

コードが明白でないということは、コードを読んだだけでは分からない重要な情報があることを意味する。コードを明白にする方法は、[[A Philosophy of Software Design 第18章 Code Should Be Obvious|A Philosophy of Software Design 第18章]]で扱われている。
