## TL;DR

アニメーション付きのコンポーネントや背景をまとめた [[react|React]] のコンポーネント集。npm のパッケージとして依存に入れるのではなく、ソースコードを自分のプロジェクトに取り込んで使う。

## 仕組み

コンポーネントは、テキストのアニメーション、アニメーション、コンポーネント、背景、マイクロインタラクションの 5 つに分類されている。ソースコードをコピーするか、CLI でコンポーネントを追加する。[[javascript|JavaScript]] と [[typescript|TypeScript]]、素の CSS と [[tailwind-css|Tailwind CSS]] から選べる。
