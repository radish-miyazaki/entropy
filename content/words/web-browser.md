## TL;DR

Web サーバに接続して Web ページを表示し、ハイパーリンクをたどるためのソフトウェア。Web ブラウザ、または単にブラウザと呼ぶ。

## 仕組み

Wikipedia によると、ブラウザは [[http|HTTP]] でサーバと通信してコンテンツを取得する。接続先は URI で指定する。取得したコンテンツは、[[html|HTML]] や XML、画像などの種類に応じて解析し、その結果をもとに文字や画像を配置して表示する。HTML のほかに、[[css|CSS]] や [[javascript|JavaScript]] にも対応している。表示できないファイルは、ダウンロードして保存するか、他のプログラムで開こうとする。

## 例

Google Chrome、Safari、Microsoft Edge、Mozilla Firefox、Opera などがある。歴史をさかのぼると、1991 年に Tim Berners-Lee が WorldWideWeb を公開し、1993 年に画像を扱える NCSA Mosaic が登場した。
