## TL;DR

アプリケーションを作ってホストするためのクラウドプラットフォーム。Web サービス、静的サイト、データベースなどをまとめて扱える。

## 仕組み

主に次のサービスを提供している。

- Web サービス: 動的な Web アプリを公開 URL でホストする
- プライベートサービス: 内部の通信だけを受けるアプリをホストする
- バックグラウンドワーカー: 非同期のジョブを動かす
- Cron ジョブ: 定期的な処理を動かす
- 静的サイト: Web サイトを無料でホストする
- [[postgresql|PostgreSQL]]: マネージドのデータベース
- Key Value: Redis 互換のデータストア
- 永続ディスク: サービスのファイルシステムへの変更を残す

デプロイはダウンタイムなしで行われ、プルリクエストごとのプレビュー環境、Infrastructure as Code、Docker にも対応している。
