## TL;DR

[[git|Git]] のプロジェクト（リポジトリ）をクラウドでホストするプラットフォーム。Git の上に、チームで共同作業するための機能を加えている。

## 仕組み

Git はファイルの変更を追跡するバージョン管理システムである。GitHub は Git をもとに、ホスティングと共同作業の機能を提供する。Issue で作業を計画・追跡し、プルリクエストでコードの変更を提案して、マージ前にレビューを受けられる。
