## TL;DR

[[git|Git]] のプロジェクト（リポジトリ）をクラウドでホストするプラットフォーム。Git の上に、チームで共同作業するための機能を加えている。

## 仕組み

Git はファイルの変更を追跡するバージョン管理システムである。GitHub は Git をもとに、ホスティングと共同作業の機能を提供する。Issue で作業を計画・追跡し、プルリクエストでコードの変更を提案して、マージ前にレビューを受けられる。

GitHub Docs によると、GitHub は計画から運用までのソフトウェア開発の工程全体を支えるプラットフォームである。Issue とプルリクエストのほかに、マージ前に変更を自動でチェックする仕組みや、[[continuous-integration|CI]]、テスト、デプロイのワークフロー、マイルストーンによる計画、リリース管理とパッケージの公開、依存関係とセキュリティの管理、AI でコードを書いたりレビューしたりする機能がある。

## 注意点

Git と GitHub は別物である。Git は手元のコンピュータで変更を追跡するソフトウェアで、GitHub は Git のリポジトリをホストし、その上に共同作業と計画の機能を加えたクラウドサービスである。Git は GitHub なしでも使えるが、GitHub は Git を土台にしている。
