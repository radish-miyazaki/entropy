## TL;DR

学習の方法によって、学んだ内容がどれだけ記憶に残るかが違うことを表した学習モデルの総称。一般にはピラミッドの層と割合で示されるが、その割合には根拠がない。

## 仕組み

よく示される図では、学習の方法ごとの定着率が次のようになっている。

| 定着率 | 学習の方法                     |
| ------ | ------------------------------ |
| 5%     | 講義を聞く                     |
| 10%    | 読書をする                     |
| 20%    | 視聴覚教材を使う               |
| 30%    | デモンストレーションを見る     |
| 50%    | グループディスカッションをする |
| 75%    | 学んだことを実践する           |
| 90%    | 他の人に教える、すぐに使う     |

## 注意点

Wikipedia によれば、10%、20%、30%、50%、90% といった割合には根拠がない。

> それぞれの割合は、10％、20％、30％、50％、90%の値になっているが、そのパーセンテージの根拠はない。
