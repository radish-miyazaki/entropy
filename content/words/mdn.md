## TL;DR

アプリケーション開発者向けに、[[html|HTML]]、[[css|CSS]]、[[javascript|JavaScript]] をはじめとする Web の技術をまとめたドキュメント。

## 仕組み

もとはブラウザベンダの Mozilla が提供していたサイトである。現在は、競合するブラウザベンダの Microsoft と Google もコミットして管理する、ブラウザベンダ共通のドキュメント集になっている。

MDN の About ページによると、2005 年に、オープンな Web 標準を記録するコミュニティ主導の wiki「DevMo」として始まり、2010 年に Mozilla Developer Network（MDN）に名前を変えた。2020 年には wiki から GitHub で管理するプロジェクトに移った。現在は Mozilla Corporation が所有するオープンソースのプロジェクトで、世界中のボランティアや、Open Web Docs、Microsoft、Google、Igalia、[[w3c|W3C]] などのパートナーと一緒に作られている。GitHub のリポジトリを通じて、誰でも内容の修正を提案できる。
