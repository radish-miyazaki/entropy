## TL;DR

Apple が Mac 向けに提供する、Unix ベースの独自の OS。以前は OS X、元は Mac OS X という名前だった。

## 仕組み

Wikipedia によると、macOS は OPENSTEP for Mach と FreeBSD から派生した Unix の OS である。土台となるアーキテクチャは、Apple が買収した NeXT の NeXTSTEP に由来する。Apple はオープンソースの中核部分を Darwin として公開し、その上に独自のコンポーネントを重ねている。

OS X Lion を除き、Mac OS X Leopard 以降のすべての版が UNIX 03 の認証を受けている。macOS Big Sur からは、ARM ベースの Apple シリコンを搭載した Mac に対応している。

## 例

一般向けの最初の版は 2001 年 3 月の Mac OS X 10.0 である。2012 年に名前を OS X に縮め、2016 年に Apple の他の OS とそろえて macOS に改めた。
