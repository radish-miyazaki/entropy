## TL;DR

[[domain-name|ドメイン名]]と [[ip-address|IP アドレス]]を対応付けるシステム。ドメイン名から IP アドレスへの変換を正引き、その逆を逆引きと呼ぶ。

## 仕組み

DNS の情報を管理する DNS サーバはインターネット上にあり、ユーザが Web サイトにアクセスする直前に使われる。DNS は [[rfc|RFC]] 1034 と RFC 1035 の仕様に基づいて実装される。

RFC 1034 によると、DNS は次の 3 つの要素からなる。

- ドメイン名空間とリソースレコード: 木構造の名前空間と、名前に結び付いたデータの仕様。名前に結び付いた情報は、個々のリソースレコード（RR）の集まりである
- ネームサーバ: ドメインの木の構造と情報を保持するサーバプログラム。名前空間のうち、完全に保持している部分については権威を持つ
- リゾルバ: クライアントの要求に応じて、ネームサーバから情報を取り出すプログラム。ユーザのプログラムとネームサーバの間に入る

権威のある情報はゾーンと呼ばれる単位でまとめられ、冗長性のために複数のネームサーバに分散して置ける。ノードのドメイン名は、そのノードからルートまでのラベルを、具体的なものから順に並べたものである。
