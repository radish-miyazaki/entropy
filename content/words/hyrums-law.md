## TL;DR

コードの挙動を変えると、それが API の変更を伴わない些細なものであっても、以前の挙動に依存している利用者が存在する、という法則である。暗黙依存関係の法則とも呼ばれる。

> コードの挙動を変更すると、その変更が API の変更を伴わない些細なものであっても、以前の挙動に依存しているユーザが存在するという法則
>
> — [[Effective Rust]]

## 例

[xkcd の「Workflow」](https://xkcd.com/1172/)は、この法則を風刺した漫画である。あるソフトウェアのアップデートで「スペースキーを押し続けると CPU が過熱する」不具合が直された。ところが、あるユーザーは CPU の温度上昇をきっかけに Emacs が Ctrl キーと認識するよう設定しており、その使い方が壊れたと苦情を言う。漫画には「すべての変更は誰かのワークフローを壊す」と添えられている。開発者が意図しない挙動であっても、利用者はそれを使いこなしてしまう。
