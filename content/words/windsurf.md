## TL;DR

[[codeium]] の開発元が作った AI エディタである。2026 年現在は Devin Desktop に名前が変わっている。

## 仕組み

Devin Desktop のドキュメントによると、コードベースを理解したうえでエージェントがコードを書く [[ide|IDE]] である。MCP サーバでエージェントの機能を広げられ、ルールや AGENTS.md でエージェントの振る舞いを変えられる。繰り返す作業は Workflows として自動化できる。Supercomplete という補完機能は、次の編集だけでなく、次に書こうとしている内容を予測する。

[[visual-studio-code|Visual Studio Code]] や [[cursor|Cursor]] の設定を取り込める。macOS、Windows、Linux で動く。

## 注意点

Devin Desktop の FAQ によると、Windsurf は Devin Desktop に名前が変わった。変わったのは名前とブランドだけで、プラン、料金、拡張機能、設定、作業中の内容は引き継がれる。Devin Desktop は、Windsurf の IDE を土台に、ローカルやクラウドのエージェントをまとめて管理する機能を足したものである。

拡張機能をマーケットプレイスから入れることはできない。
