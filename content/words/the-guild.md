## TL;DR

[[graphql|GraphQL]] のオープンソースのツール群を開発・保守している企業（[公式サイト](https://the-guild.dev/)）。2015 年から GraphQL のツールを保守しており、他のチームが手放したプロジェクトも引き継いでいる。

## 例

公式サイトによると、主に次のプロジェクトを手がけている。

- [[graphql-codegen|GraphQL Code Generator]]: 型安全なコードを生成する
- GraphQL Tools: スキーマを扱うツール。2020 年に Apollo から引き継いだ
- GraphQL Yoga: GraphQL サーバ。2021 年に Prisma から引き継いだ
- Hive: オープンソースの GraphQL Federation プラットフォーム
- GraphQL Inspector: スキーマの変更をチェックする
