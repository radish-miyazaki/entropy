## TL;DR

OWASP が公開している、[[go|Go]] で Web アプリケーションを開発する人向けのセキュリティに関するベストプラクティス集である。

## 仕組み

ガイドは次の章で構成されている。

- Input Validation
- Output Validation
- Authentication and Password Management
- Session Management
- Access Control
- Cryptographic Practices
- Error Handling and Logging
- Data Protection
- Communication Security
- System Configuration
- Database Security
- File Management
- Memory Management
- General Coding Practices
