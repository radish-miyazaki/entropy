## TL;DR

Graphical User Interface の略。コンピュータグラフィックスとマウスなどのポインティングデバイスを使って操作する、視覚的なユーザインタフェースである。文字で操作する CUI（キャラクタユーザインタフェース）と対比される。

## なぜ必要か

コマンドを覚えて入力しなくても、画面上のアイコンやメニューを選ぶだけで操作できる。

## 仕組み

GUI は、作業の起点となるデスクトップ、アプリケーションやデータを扱う単位であるウィンドウ、使えるコマンドを階層的に並べたメニュー、データやアプリケーションを絵で表したアイコン、よく使う機能を置いたボタンなどでできている。ウィンドウ、アイコン、メニュー、ポインタの頭文字を取って WIMP とも呼ばれる。マウスで選択や実行を指示し、キーボードショートカットも併用する。タッチパネルでは、画面上のボタンやアイコンに直接触れて操作する。

## 例

- 1963 年のアメリカ空軍の防空管制システム SAGE が、実用化された最初の GUI とされる。
- 1970 年代に Xerox の Alto と Smalltalk の環境で、ウィンドウ、マウス操作、アイコンといった今の GUI の主な要素が形作られた。
- [[ooui|OOUI]] や [[zui|ZUI]] は、GUI の操作モデルや形態の 1 つである。
