## TL;DR

2015 年にリリースされた、クロスプラットフォーム対応のテキストエディタ。オープンソースで開発されており、Sublime Text や Atom に影響を受けている。

## なぜ必要か

[[javascript|JavaScript]] のコミュニティで特に人気が高い。最大の特徴は拡張性で、JavaScript 開発向けの拡張機能のエコシステムが充実している。[[eslint|ESLint]] や [[prettier|Prettier]]、[[wallaby|Wallaby]] なども拡張機能としてエディタに統合できる。

> First launched in 2015, it rapidly rose to become the most popular editor in the JavaScript community.
> What makes VS Code special is its incredible extensibility.
> There’s a rich ecosystem of VS Code extensions, especially for JavaScript development, as we’ll soon see.

## 例

コマンドパレットから「Preferences: Keymaps」を選ぶと、利用できるキーマップの一覧がサイドバーに表示される。Emacs、Vim、IntelliJ IDEA などのキーマップを入れられるので、他のエディタから移行しやすい。
