## TL;DR

- [[infrastructure-as-code|Infrastructure as Code（IaC）]]の基礎から始め、[[terraform|Terraform]] とは何か、使うと何がうれしいかを解説する本である。
- Terraform を使ったエンタープライズレベルのインフラ構築と管理までを扱う。Packt Publishing の「HashiCorp Infrastructure Automation Certification Guide」の翻訳書である。

## 対象読者

Terraform Associate 試験（HashiCorp Certified: Terraform Associate）を受ける人に向けて書かれた本だが、IaC や Terraform を基礎から学びたい人にも向いている。[[aws|AWS]]、Google Cloud、Azure の各クラウドに合わせて解説している。

前提として、次の知識や経験があるとよい。

- AWS、Google Cloud、Azure などのクラウドサービスの基本
- Azure DevOps や [[github|GitHub]] などの DevOps ツールの知識
- PowerShell や Bash でスクリプトを書いた経験
