## TL;DR

- [[llm|大規模言語モデル]]（LLM）に与える、プロンプトを含む多様な入力情報が「コンテキスト」である。限られた入力の中で何を与え、何を捨て、どう良い状態を保つかという技術の総体を「[[context-engineering|コンテキストエンジニアリング]]」と呼ぶ。
- AI モデルの仕組みや API の挙動をコンテキストの観点から読み解き、[[rag|RAG]] や [[ai-agent|AI エージェント]]の開発で使うコンテキストエンジニアリングの技法を紹介する本である。

## 目次

3. 第3章 指示プロンプト開発の基礎
4. 第4章 RAGにおけるコンテキスト整備
5. 第5章 AIエージェント×ワークフローによる作業自動化
