## TL;DR

- Robert C. Martin が提唱した[[clean-architecture|クリーンアーキテクチャ]]の考え方に沿って、Web アプリケーションをどう作るかを実装コードとともに解説する本である。
- 副題は「[[hexagonal-architecture|ヘキサゴナルアーキテクチャ]]によるクリーンなアプリケーション開発」。原題は「Get Your Hands Dirty on Clean Architecture: Build 'clean' applications with code examples in Java」。

## 対象読者

ソフトウェア設計に興味がある開発者や、クリーンアーキテクチャとその実装方法を知りたい開発者に向けた本である。

サンプルコードは [buckpal](https://github.com/thombergs/buckpal) で公開されている。言語は Java（一部 [[kotlin|Kotlin]]）、フレームワークは Spring Boot だが、オブジェクト指向の言語であれば考え方はそのまま使える。

読むときの注意として、翻訳者によると、本書のサンプルコードでは[[domain-driven-design|ドメイン駆動設計]]でいうアプリケーションサービスがドメインサービスに取り込まれている。本書は「クリーンなアーキテクチャをどう実現するか」に主眼を置いており、アプリケーションのコアの中の境界（ドメイン層とアプリケーション層）はそこまで厳格に区別していない。そのため、ドメインサービスが受信ポートを実装し、内部で送信ポートを扱う。これは「ドメイン層はアプリケーション層に依存してはならない」というルールを守っていないが、サンプルコード程度の規模では区別するコストのほうが大きいため、あえて区別していない。
