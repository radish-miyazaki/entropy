## TL;DR

- [[erlang|Erlang]] の入門書で、[日本語訳が Web で公開されている](https://www.ymotongpoo.com/works/lyse-ja/index.html)。日本語の書籍版は『すごいErlangゆかいに学ぼう！』である。

書籍版（日本語訳）を持っている。ただ、[結びの章](https://www.ymotongpoo.com/works/lyse-ja/ja/34_conclusion.html#lyse)によると書籍版は 600 ページほどあり、この分量なら Web で読んだほうが楽かもしれない。なお、Erlang は今ではバージョン 27 まで進んでいる。
