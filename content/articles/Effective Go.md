## TL;DR

明確で Go らしい（idiomatic な）コードを書くためのヒントをまとめた、[[go|Go]] 公式のドキュメント。2009 年の Go の公開に合わせて書かれ、現在は積極的には更新されていない。

## 内容

Go には独自の性質やイディオムがある。C++ や Java のプログラムをそのまま Go に書き換えても、満足のいく結果にはなりにくい。命名、フォーマット、プログラムの組み立て方について Go の慣習に従うと、ほかの Go プログラマにとって読みやすいコードになる。

言語仕様、Tour of Go、How to Write Go Code を読んだ後に読むことを想定している。フォーマット、コメント、命名、セミコロン、制御構文、関数、データ、初期化、メソッド、インタフェース、ブランク識別子、埋め込み、並行処理、エラーといった話題を扱う。

コア言語のガイドとしては今でも有用だが、ジェネリクスやモジュール、その後に追加された標準ライブラリの機能は扱っていない。変更点はリリースノートで確認する。
