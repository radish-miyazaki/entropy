## TL;DR

- Anthropic Academy が Skilljar で公開している無料コースである。
- Claude Code を単発のプロンプトで使っている開発者に向けて、長く監督の少ないセッションの進め方、チームでのワークフロー、その結果の検証方法を教える。

## 内容

コースは 4 つの単元と最後のクイズで構成されている。

### Steer the Work

長いセッションの進め方を扱う。plan mode でタスクの範囲を決め、コンパクションを指示し、rewind メニューで方向を直す。人が手を動かす進め方と、自律的に走らせる進め方の選び方も学ぶ。

### Configure Claude

無駄のない CLAUDE.md を書き、繰り返す手順を skill としてまとめる。permission mode を選び、hooks でルールを強制する方法を扱う。

### Automate Repeat Work

プロンプトを routine として定期実行し、headless モードを使う。managed code review や GitHub Action で、Claude を Pull Request につなぐ方法も学ぶ。

### Verify and Share

監督なしで走らせた結果を検証し、hooks でテスト結果に応じてターンを止める。最後に、設定一式を plugin としてまとめ、チームに配る方法を扱う。

## キーワード

- Claude Code
- CLAUDE.md
- plan mode
- hooks
- headless モード
- GitHub Actions
